## Arbori
- balansat = diferenta intre numar de noduri subarbore stang si subarbore drept sa nu depaseasca un anumit prag (by default 1)
- rotire stanga si rotire dreapta
    - pentru rotirea stanga, nodurile de interes sunt "radacina" (nod sus) si nodul copil dreapta
    - restul de subarbori se pot inlocui (renota) cu altceva
    - copilul drepta trece in locul radacinii
    - radacina trece copil stanga a noii radacini
    - subarborele stang al vechiullui copil dreapta trece subarbore drept al noului copil stanga
    (sau subarborii exteriori raman cu legaturile neschimbate si se completeaza unde a ramas loc cu ce a ramas in aer)

## Rosu-Negru
- radacina este neagra
- toate referintele NULL sunt negre
- daca un nod este rosu, ambii copii sunt negri
- de la un nod catre orice frunza (referinta NULL a lui) trebuie sa dam de acelasi numar de noduri negre (inaltimea neagra a nodului respectiv in arbore fara a numara nodul respectiv)
- pentru n noduri in arbore, h maxim este $2log(n+1)$
- insert, delete - average case O($logn$), worst case O(n) (pentru arbore degenerat - lista simplu inlantuita)
- in cazul in care inseram/stergem din arbore, trebuie sa ne asiguram ca respectam proprietatile de arbore rosu-negru -> algoritmul de fix la insert (by default se insereaza doar noduri rosii)

```
T = arbore (ne putem referi la el prin root)
z = nodul recent inserat
RB-INSERT-FIXUP(T,z)
While z.p.color == RED // cat timp parintele este rosu (bunicul garantat este negru, arborele fiind valid inainte de inserarea nodului nou)
	If z.p == z.p.p.left // daca parintele este fiul stang al bunicului sau
		y = z.p.p.right // retinem in variabila y fratele drept al parintelui (unchiul)
		If y.color == RED // daca unchiul este rosu
			z.p.color = BLACK  //caz1 // parintele devine negru
			y.color = BLACK // unchiul devine negru
			z.p.p.color = RED // bunicul devine rosu
			Z = z.p.p // nodul curent la care ne referim acum devine bunicul si problema se reia
		Else if z == z.p.right // daca nodul curent este fiu dreapta al parintelui
			Z = z.p   // caz 2 // problema se muta la parinte
			LEFT-ROTATE(T,z) // rotire stanga in functie de nodul curent, referinta catre nodul  curent nu se schimba
		    z.p.color = BLACK  //caz 3 // coloram parintele nodului curent cu negru
		    z.p.p.color = RED // coloram bunicul cu rosu
		    RIGHT-ROTATE(T, z.p.p) // facem rotire dreapta in functie de bunic
	Else if z.p == z.p.p.right
        y = z.p.p.left
        if y.color == RED
            z.p.color = BLACK  //caz1 // parintele devine negru
			y.color = BLACK // unchiul devine negru
			z.p.p.color = RED // bunicul devine rosu
			Z = z.p.p // nodul curent la care ne referim acum devine bunicul si problema se reia
        Else if z == z.p.left // daca nodul curent este fiu stanga al parintelui
			Z = z.p   // caz 2 // problema se muta la parinte
			RIGHT-ROTATE(T,z) // rotire dreapta in functie de nodul curent, referinta catre nodul curent nu se schimba
		    z.p.color = BLACK  //caz 3 // coloram parintele nodului curent cu negru
		    z.p.p.color = RED // coloram bunicul cu rosu
		    LEFT-ROTATE(T, z.p.p) // facem rotire stanga in functie de bunic
T.root.color = BLACK // daca ajungem din greseala sa coloram radacina cu rosu, rectificam
```
