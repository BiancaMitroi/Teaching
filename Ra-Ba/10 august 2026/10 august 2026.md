## Complexitate: O(...)

- Pentru populare/afisare cu elemente: O(n) (n = dimensiunea sirului) si pentru vector si pentru lista

- inserare pe ultima pozitie:
    - vector: O(1) (+ realocare)
    - lista cand stim referinta ultimului element: O(1)
    - lista cand NU stim referinta ultimului element: O(n)
- inserare in interior:
    - vector: O(n)
    - lista:
        - cautat referinta a elementului dupa care vrem sa facem inserarea: O(n)
        - inserarea efectiva: O(1)
- stergere de ultim element:
    - lista: O(1) (operatia efectiva de stergere) + cautarea referintei ultimului + penultimului element (O(n))
    - vector: O(n) (shiftarea elementelor cu o pozitie mai la stanga + realocare de vector)

## Stiva
- operatii posibile:
    - insert last (push)
    - delete last (pop)
- reprezentare:
    - vector
    - lista, cu prelucrare pe ultimul element SAU
    - lista, cu prelucrare pe primul element
        - insert first (push) - O(1)
        - delete first (pop) - O(1)

![figure2](../figures/10%20august%202026%20figure%202.png)

## Coada
- operatii posibile:
    - insert last (enqueue)
    - delete first (dequeue)
- reprezentare:
    - vector:
        - insert: O(1)
        - delete: O(n)
    - lista:
        - delete: O(1) (first)
        - inssert: O(1) (pentru ca stim referinta last-ului)

## Tabele de dispersie
- acces indexat (indecsii nu trebuie sa fie neaparat numere)
- problema de coliziune: 2 sau mai multe valorise potrivesc pe aceeasi pozitie => liste inlantuite (daca nu se vrea realocarea vectorului) sau realocare cu dublul dimensiunii anterioare
- inserarea/stergerea (se face punand pe pozitie valoarea 0)/cautarea se fac prin functii (de obicei Value % dimensiune determina pozitia pe care sa inserez in tabela)
